# fourman-project


<br>

## 프로젝트 소개
팀원의 실제 경험으로

청약시 서버에 엄청난 인원이 몰려서 서비스 마비가 일어났고

서비스 마비에 따른 추가적인 피해를 겪을수 있고

이러한 서비스 장애는 주변에서 흔히 볼 수 있는 수강신청, 티켓 예매, 경품 응모 등 다양한 곳에서 발생할 수 있습니다.

그래서 게시판페이지에 트래픽을 걸고 테스트 해볼 수 있는 서비스를 만들었습니다.

<br>

- **Tools**: IntelliJ IDEA, k6

## 프로젝트 후기

2주간 팀프로젝트를 하면서 지금까지 학습한 내용을 다시 적용하는것에 초점을 맞춰서 이번 프로젝트를 임하였다.

그렇게 하면서 또 MyBatis와 같은 해보지 못한 기술을 적용시켜 보기도 하고 적용중 발생하던 문제들을 해결하기도 해서 좋은 경험이었다고 생각한다.

이번에 또 드러나지는 않지만 test code 작성 또는 Setter를 지양한 코드 등 새롭게 배운내용을 다음 프로젝트에서는 좀 더 자연스럽게 적용하고 싶은 생각이 들었다.
